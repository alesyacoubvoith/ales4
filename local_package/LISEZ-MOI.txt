========================================================
  Support IT — Plateforme Helpdesk & Stock (LOCAL)
========================================================

SUPER SIMPLE — tu as juste besoin d'installer PYTHON une fois.
(Pas de Node, pas de MongoDB, pas de yarn. Rien d'autre.)

------------------------------------------------
ÉTAPE 1 — Installer Python (une seule fois)
------------------------------------------------
- Va sur : https://www.python.org/downloads/
- Clique sur "Download Python".
- Lance l'installateur.
- !!! TRÈS IMPORTANT !!! Sur le 1er écran, COCHE la case
  "Add Python to PATH" avant de cliquer sur "Install Now".
- Attends la fin, clique "Close".

------------------------------------------------
ÉTAPE 2 — Lancer l'application
------------------------------------------------
- Double-clique sur le fichier  LANCER.bat
- Une fenêtre noire s'ouvre, installe quelques petits trucs (1re fois),
  puis démarre. NE FERME PAS cette fenêtre.
- Ton navigateur s'ouvre tout seul sur http://localhost:8001

------------------------------------------------
ÉTAPE 3 — Première configuration (1re fois seulement)
------------------------------------------------
- Au tout premier lancement, l'appli te demande de CRÉER ton
  compte administrateur (ton nom + un ID de connexion, ex: ADMIN).
- Ce compte te servira à te connecter (pas de mot de passe).
- Ensuite, va dans "Comptes & accès" pour créer les comptes de
  tes collègues (employé ou admin), avec ou sans accès au parc info.

------------------------------------------------
ÉTAPE 4 — Partager avec tes collègues
------------------------------------------------
- Ils doivent être sur le MÊME réseau / Wi-Fi que toi.
- Trouve ton IP : ouvre "cmd", tape  ipconfig , regarde "Adresse IPv4"
  (ex : 192.168.1.42).
- Tes collègues ouvrent dans leur navigateur :
      http://192.168.1.42:8001
- Si Windows affiche "Autoriser l'accès ?" => clique AUTORISER.

------------------------------------------------
FONCTIONS UTILES
------------------------------------------------
- STOCK : bouton "Importer Excel" pour charger ton stock d'un coup
  (clique d'abord "Modèle" pour avoir le bon format .xlsx à remplir).
- PARC INFORMATIQUE : ordinateurs / imprimantes / tablettes,
  avec export Excel.
- TICKETS : on peut joindre une pièce jointe (capture, PDF, photo).

------------------------------------------------
BON À SAVOIR
------------------------------------------------
- Les données sont enregistrées dans  data.json  (à côté de LANCER.bat).
- Les pièces jointes sont dans le dossier  uploads/ .
  -> Sauvegarde ces deux éléments pour conserver tes données.
- Pour éteindre : ferme la fenêtre noire.

Un souci ? Renvoie une capture d'écran de la fenêtre noire.
